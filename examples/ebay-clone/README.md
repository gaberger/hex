# eBay Clone MVP README

## Prerequisites

To run this project, you need the following installed:

- **Rust**: Ensure Rust is installed on your system by running `rustc --version`. If not, install it from [rust-lang.org](https://www.rust-lang.org/tools/install).
- **Spacetime CLI**: Follow the installation instructions for Spacetime CLI at [docs/specs/ebay-spec-024](docs/specs/ebay-spec-024).
- **Bun**: Install Bun from [bun.sh](https://bun.sh/docs/installation).

## Environment Variables

Set up the following environment variables in your shell or `.env` file:

```bash
export DATABASE_URL=your_database_url
export BACKEND_PORT=8080
export VITE_PORT=5173
```

Replace `your_database_url` with the actual URL of your database.

## Starting the Project

Run the following command to start the project:

```bash
./start.sh
```

This script will:
- Launch STDB (Spacetime Database).
- Publish the marketplace.
- Start the backend on port 8080.
- Start Vite on port 5173.
- Print all URLs involved.

## Troubleshooting

If you encounter any issues, consider the following troubleshooting steps:

- **Orphan Processes**: Ensure that `start.sh` properly traps SIGINT to kill child processes. Verify using spec-022: [docs/specs/ebay-spec-022](docs/specs/ebay-spec-022).
- **Stale Port Bindings**: If ports 8080 or 5173 are still in use, check and kill any lingering processes. Use `lsof -i :8080` or `lsof -i :5173` to find them.
- **Logs and Errors**: Check the logs generated by each service for more details on what might be going wrong.
